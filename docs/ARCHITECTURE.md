# 架构

```
mod.toml + IR 数据
        │
        ├── native/ (Rust)：解析、校验、路由
        ├── lib/ (C)：资源源抽象（dir / mem）
        └── vulkan-layer/ (C++)：渲染层钩子与加载
```

## 资源源

`efml4a_source` 是公开接口，只有 `dir` 和 `mem` 两个后端。VFS 不在公开仓；
需要 VFS 时由私有组件通过独立进程/插件提供，公开库不链接它。

## 格式

`mods/example-mod` 是合成数据的参考包，展示顶点声明、子网格、骨骼映射、
blendshape、材质/贴图和完整性校验。mod 格式不是游戏资源格式，不携带游戏数据。

## 边界

公开仓只做“拿到资源之后怎么用”，不回答“怎么从游戏包里拿资源”。
